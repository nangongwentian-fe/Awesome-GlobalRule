# local-agents-template.md

## 1. 目标

本文件提供局部 `AGENTS.md` 的推荐模板。  
局部 `AGENTS.md` 应比根级文件更短、更具体、更贴近当前目录，不要重复复制全局规则。

---

## 2. 使用原则

1. 只记录当前目录真正高频复用、容易踩坑、容易被重复纠正的内容。
2. 不要把根级 `AGENTS.md` 的通用规则整份复制到局部文件。
3. 局部文件应尽量短、稳、可直接执行。
4. 若某条经验已过时，应直接在局部文件中修改，而不是继续堆新条目。

---
